# Security

Please report security problems privately, not in a public issue:

- use [Report a vulnerability](https://github.com/PyModel/ProxyPort/security/advisories/new) on this repository, or
- email hello@pymodel.com with "Security" in the subject.

Include your ProxyPort version (Settings → About), your macOS version and the steps that show the problem.

Fixes ship in the next release. ProxyPort checks for updates daily and installs them when you say so.
