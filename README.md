# ProxyPort

ProxyPort lives in your Mac's menu bar and shows every port that AI agents and dev servers have open: the project, branch, memory, CPU, traffic and the agent that started it. Then it stops the ones you forgot.

This repository holds ProxyPort's releases, changelog and issue tracker. The app's source code is private.

## Download

- [Download ProxyPort for Mac](https://proxyport.pymodel.com/download). macOS 14 or later.
- Or take a disk image from [Releases](https://github.com/PyModel/ProxyPort/releases). Each one is signed and notarized, with a SHA-256 checksum next to it.

A license is $5 a year for one Mac. ProxyPort checks for updates daily and installs them when you say so; [the changelog](CHANGELOG.md) lists what changed.
